🕌 Gebetszeiten Widget für deine Moschee-Seite

Diese Anleitung zeigt dir drei Wege, die Gebetszeiten auf deine Dokploy-Seite (z.B. offenbachmevlana.de) einzubinden.

1️⃣ Variante A: iframe (am einfachsten)

Eine Zeile HTML in deiner Seite reicht:

<iframe src="https://salah.chargedesk.de/widget?city=Offenbach&lang=de"
        width="100%" height="380" frameborder="0"
        style="border:2px solid #c8a86b;border-radius:12px;max-width:480px">
</iframe>

Vorteile: Funktioniert sofort, eigenständig, lädt automatisch die neuesten Zeiten.
Nachteile: Sieht aus wie ein eingebettetes Widget (nicht in dein Design integriert).

2️⃣ Variante B: iframe mit eigenem Design

Du kannst die Farben an deine Moschee-Markenfarben anpassen:

<iframe src="https://salah.chargedesk.de/widget?city=Offenbach&lang=de&
                bg=%23064e3b&fg=%23ffffff&accent=%23d4af37&days=7"
        width="100%" height="500" frameborder="0"
        style="border:0;border-radius:12px">
</iframe>

URL-Parameter

ParameterDefaultBeschreibung
city—Stadt (z.B. "Offenbach", "Berlin", "Mekka")
langdeSprache: de, tr, ar, en
dateheuteBestimmtes Datum (z.B. 2026-08-13)
days11-30 Tage Vorschau (Tabelle statt Grid)
themedarkdark oder light
bg#0a4a32Hintergrundfarbe (HEX, URL-encoded: %23 statt #)
fg#f0f5e8Textfarbe
accent#c8a86bAkzentfarbe (Gold-Look)

3️⃣ Variante C: JavaScript fetch (custom UI)

Wenn du die Gebetszeiten direkt in dein eigenes Layout integrieren willst:

<div id="gebetszeiten"></div>

<script>
fetch('https://salah.chargedesk.de/api/times?city=Offenbach&date=2026-08-13')
  .then(r => r.json())
  .then(d => {
    document.getElementById('gebetszeiten').innerHTML = \`
      <h3>\${d.city.name}</h3>
      <ul>
        <li>İmsak: \${d.imsak}</li>
        <li>Güneş: \${d.sunrise}</li>
        <li>Öğle: \${d.dhuhr}</li>
        <li>İkindi: \${d.asr}</li>
        <li>Akşam: \${d.maghrib}</li>
        <li>Yatsı: \${d.isha}</li>
      </ul>
      <p>Methode: \${d.method}</p>
    \`;
  });
</script>
JSON-Format der API: 
{
  "city": {"name": "Offenbach", "country": "DE", "timezone": "Europe/Berlin", "lat": 50.10, "lng": 8.77},
  "date": "2026-08-13",
  "imsak": "03:53",
  "sunrise": "06:04",
  "dhuhr": "13:35",
  "asr": "17:33",
  "maghrib": "20:54",
  "isha": "22:54",
  "method": "Turkey (Diyanet)"
}

📥 Download als Standalone-HTML

Du kannst das Widget auch als eigenständige HTML-Datei herunterladen und auf deinen Server kopieren:

  1. Öffne https://salah.chargedesk.de/widget?city=Offenbach&lang=de im Browser
  2. Rechtsklick → "Seite speichern unter" (z.B. gebetszeiten-offenbach.html)
  3. Lade die Datei auf deinen Dokploy-Server hoch
  4. Binde sie ein: <iframe src="/gebetszeiten-offenbach.html"></iframe>

Die Datei ist ~4.4 KB klein und komplett self-contained (CSS inline, kein externes JS).

🔄 Auto-Update

Das Widget zeigt immer die aktuellen Zeiten:

  • Bei jedem Seitenaufruf wird neu berechnet (mit Adhan-Bibliothek, Diyanet-Turkey-Methode)
  • Kein Cache → immer frische Daten
  • Berücksichtigt IANA Timezone + Sommerzeit/Winterzeit
  • Validiert gegen 275.000 echte IGMG-Server-Daten
💡 Tipp: Wenn du nur die heutigen Zeiten brauchst, nimm Variante A. Für Wetter-ähnliche Integration in dein Design nimm Variante C. Für 7-Tage-Kalender nimm Variante B mit &days=7.
⚠️ CORS aktiviert: Das Widget kann von jeder Domain eingebunden werden. Falls dein Browser/Erweiterungen Probleme machen, prüfe die DevTools-Konsole.
