API-Dokumentation

JSON API — alle Endpoints sind keyless und CORS-aktiviert. Direkt aus dem Browser abrufbar.

📡 Endpoints

GET /api/cities?country=DE&q=münchen          # Städte suchen
GET /api/times?city=Offenbach&date=2026-08-13   # Tageszeiten
GET /api/times/range?city=Offenbach&start=2026-08-13&days=7
GET /api/times/month?city=Offenbach&year=2026&month=8
GET /api/distance?from=Offenbach&to=Mekka       # Seferi-Distanz
GET /api/hadith/today                            # Hadith des Tages
GET /api/holidays?from=2026-08-01&to=2026-08-31  # Islamische Feiertage
